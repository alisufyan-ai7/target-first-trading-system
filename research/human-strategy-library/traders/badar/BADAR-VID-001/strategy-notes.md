# BADAR-VID-001 — Strategy Notes

## What this source adds

BADAR-VID-001 contributes **entry-confirmation vocabulary and location/confluence clues**, not a complete strategy.

The source-supported decision hierarchy currently looks like:

```text
pre-existing area / zone
    -> price interacts with the area
    -> observe confirmation behavior
       - engulfing
       - two-candles rejection
       - momentum shift
       - inverse closing
    -> stronger evidence when a second confirmation occurs at the same zone
```

This hierarchy is provisional because the source does not explain how the first “area / zone” is chosen.

## Most important methodological implication

Do not build “Engulfing Engine U” from this source.

The source itself shows why that would be premature: engulfing is presented in trend context and repeatedly demonstrated at highlighted zones, while the final section explicitly values **multiple confirmations at the same location**.

The missing selection layer may be more important than the candle pattern.

## No-trade logic

The source provides only pattern-definition failures, not a broad no-trade framework.

This is a major research gap.
