# Cross-Source Human Trading Synthesis

This folder is for concepts supported by more than one source.

Do not put a concept here merely because it sounds plausible.

Examples of useful future syntheses:

- repeated no-trade conditions;
- timing/session effects;
- structure hierarchies;
- level-selection logic;
- entry patience / non-chasing behavior;
- stop placement;
- target selection;
- trade-management behavior;
- visual context that repeatedly distinguishes high-quality from low-quality setups.

Each synthesis must reference the underlying source IDs.
